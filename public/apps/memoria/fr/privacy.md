# Politique de confidentialité de Memoria

Date d'entrée en vigueur : August 7, 2026

Memoria (ci-après l'« Application ») est un outil pour enregistrer les anniversaires, les dates commémoratives et les jours importants. Nous prenons votre vie privée très au sérieux. L'Application ne comporte ni comptes ni serveurs, et elle ne collecte ni ne téléverse aucune de vos informations personnelles vers nous.

## 1. Quelles informations nous collectons
Nous ne collectons aucune information personnelle. Le contenu que vous créez dans l'Application (comme les noms, les dates, les notes et les couleurs) est stocké uniquement localement sur votre appareil.

## 2. Synchronisation iCloud
Si vous êtes connecté à iCloud et avez activé la synchronisation, vos données sont synchronisées entre vos propres iPhone, iPad et Apple Watch via la base de données privée CloudKit d'Apple. Ces données sont stockées dans votre compte iCloud personnel, protégées par la politique de confidentialité d'Apple, et le développeur ne peut y accéder, les lire ou les obtenir d'aucune manière.

## 3. Face ID et code d'accès
Si vous activez le verrouillage de l'application, l'Application utilise l'authentification locale du système (Face ID / Touch ID / code d'accès de l'appareil) pour déverrouiller. Les données biométriques associées sont traitées localement sur votre appareil par le système ; l'Application n'accède jamais à aucune information biométrique, ne la stocke ni ne la transmet.

## 4. Notifications et rappels
L'Application utilise des notifications locales pour vous rappeler les dates commémoratives aux moments que vous définissez. Le contenu des notifications est généré uniquement sur votre appareil et ne transite par aucun serveur.

## 5. Tiers et suivi
L'Application ne contient aucune publicité, analyse de tiers, suivi d'événements ni SDK de suivi, et ne partage aucune donnée avec un tiers.

## 6. Conservation et suppression des données
Vos données sont entièrement sous votre contrôle. Vous pouvez modifier ou supprimer des enregistrements dans l'Application à tout moment ; pour supprimer des données dans iCloud, gérez-les sous « Réglages → iCloud » sur votre appareil. La désinstallation de l'Application supprime les données locales.

## 7. Confidentialité des enfants
L'Application ne cible pas les enfants de moins de 13 ans pour la collecte d'informations ; puisque nous ne collectons aucune donnée personnelle du tout, elle convient aux utilisateurs de tous âges.

## 8. Modifications de cette politique
Si cette politique est mise à jour, nous publierons la dernière version sur cette page et mettrons à jour la date d'entrée en vigueur.
