# Assistance TraceApp

Bienvenue sur TraceApp. Si vous rencontrez des problèmes ou avez des suggestions, n'hésitez pas à nous contacter via les canaux ci-dessous.

## Contact et assistance technique
- E-mail d'assistance : flywithbug@163.com
- Assistance professionnelle WeChat : en ligne en semaine de 10:00 à 19:00 ; vous pouvez nous ajouter via le QR code d'assistance dans l'application.

## Envoyer un retour
Lorsque vous envoyez un retour, nous vous recommandons de fournir autant que possible les éléments suivants afin que nous puissions localiser et résoudre le problème plus rapidement :

- Titre : Une brève description de votre problème ou de votre suggestion.
- Type : Bug/erreur, demande de fonctionnalité, interaction/expérience, ou autre.
- Description détaillée : Étapes pour reproduire, comportement attendu et résultat réel ; les captures d'écran sont les bienvenues.
- Évaluation de l'expérience : de 1 à 5 étoiles.
- Coordonnées facultatives : E-mail ou QQ, afin que nous puissions vous répondre.
- Informations système : Modèle de l'appareil, version de l'OS, etc., pour nous aider à diagnostiquer.

## FAQ

### Comment ajouter l'assistance WeChat ?
Sous « Rejoindre notre communauté », appuyez longuement sur le QR code de l'assistance professionnelle WeChat pour le reconnaître et l'ajouter. L'assistance est en ligne en semaine de 10:00 à 19:00.

### Impossible de rejoindre le Groupe QQ 2 ?
Le Groupe QQ 2 est complet. Veuillez rejoindre le Groupe QQ 1 (574966492).

### Quelles informations dois-je inclure lorsque je donne un retour ?
Nous vous recommandons de fournir un titre, le type de problème, une description détaillée (y compris les étapes pour reproduire), une évaluation de l'expérience et des coordonnées facultatives, et vous pouvez inclure des informations système pour faciliter le diagnostic.
