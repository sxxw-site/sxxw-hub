## Submitting Feedback
When submitting feedback, we recommend providing as much of the following as possible so we can locate and resolve the issue faster:

- Title: A brief description of your issue or suggestion.
- Type: Bug/error, feature request, interaction/experience, or other.
- Detailed description: Steps to reproduce, expected behavior, and actual result; screenshots welcome.
- Experience rating: 1–5 stars.
- Optional contact info: Email or QQ, so we can reply to you.
- System information: Device model, OS version, etc., to help us troubleshoot.

### Can't join QQ Group 2?

### What information should I include when giving feedback?
We recommend providing a title, issue type, detailed description (including steps to reproduce), experience rating, and optional contact info, and you may include system information to help with troubleshooting.
